# Library Management System  

## Description  
A C++ project that manages a library system with three types of users — **Students**, **Professors**, and **Library Staff**.  
The system allows users to **sign up / log in**, and provides access to **free books**, **paid books**, and **professor-specific books**.  
All data is stored efficiently using **hash maps**, and the project is built entirely with **Object-Oriented Programming (OOP)** concepts including **inheritance** and **encapsulation**.  

## Features  
- Three user roles: Student, Professor, Library Staff  
- Book management (free, paid, and professor-related)  
- Sign up / Log in functionality  
- Data hashing using hash maps  
- Built fully using OOP principles  

## Technologies Used  
- **Language:** C++  
- **Concepts:** OOP (Inheritance, Encapsulation), Hash Maps
